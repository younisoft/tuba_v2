# TBOS My Properties — State Matrix

**Status:** Documentation only. Companion to `TBOS_MY_PROPERTIES_UX_ARCHITECTURE.md`.
**Sourcing discipline:** every row is marked `VERIFIED` (cites a Phase A audit section — either `OBSERVED BEHAVIOR` live or `CODE FACT`) or `FUTURE STATE` (a state this architecture requires but that Phase A could not observe, because observing it would have required an irreversible/destructive action, or because no such capability exists yet in legacy). No state below was invented without one of these two labels.

## Explicitly out of scope for this matrix

States requiring an irreversible live action to observe (a completed Promotion purchase, a completed Service booking, an actual authority rejection, a fully-expired-license promotion attempt) were **not** driven to completion in Phase A per its own stop condition (§8 of the audit's governing instructions), and are marked `FUTURE STATE` above rather than fabricated. Closing these `OPEN QUESTION`s (also listed in the audit's §28) is recommended before Phase C implementation locks in exact copy/behavior for them.
