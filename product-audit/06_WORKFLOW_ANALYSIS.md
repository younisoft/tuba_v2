# Workflow Analysis

## Listing Publishing

Observed entry: Post Listing. The first step asks the user to choose between Sell or Rent Property and Daily Rentals, then continue. This is a clear fork, but the first screen does not yet educate users about required documents, REGA license validation, media standards, or credit implications.

## Listing Management

Observed entry: My Listings. Users filter by Listing ID, REGA Ad License Number, Purpose, and Property Type; then act from a table with property, timeline, performance, status, upgrades, and actions. Lifecycle states include Active, Draft, Pending, Removed, and Ad License Requests.

## Lead Management

Observed entry: TruLeads. Users can view trend controls, filter/search, add a new lead, and add tasks. This is the most CRM-like workflow, but visible automation and prioritization are limited.

## Credits and Package Workflow

Observed entries: Credits Usage and Credits & Packages. Users can review available/used/total credits, inspect usage history, top up credits, and browse packages. The workflow is transparent but reactive.

## Listing Recovery Workflow (Draft / Removed)

Observed entries: My Listings → Draft and Removed tabs. A listing stuck in Draft with "Insufficient Credits" and a listing in Removed with "Ad License Expired" both expose the same "Publish Now" button, but neither row explains the fix inline (top up credits vs. renew the FAL license on the Licenses screen) — the user has to already know which of two entirely different settings screens to visit. "Deleted" listings also carry a live "Publish Now", implying manual deletion is reversible, which isn't otherwise documented.

## License and Compliance Workflow

Observed entry: Settings → Licenses. The agency's single FAL license (with CR number, owner, and "Valid until" date) underlies every listing's REGA ID, and can be toggled on/off for staff visibility via "Share with agency staff". Nothing in the product connects this screen forward to which specific listings would be affected if the license lapsed — that link only becomes visible after the fact, as an "Ad License Expired" status on a Removed listing.

## Agent Performance / TruBroker Workflow

Observed entry: Agent Performance. Three prerequisites gate "Unlock TruBroker™": Complete Profile, 2+ Active Listings, Active Bayut Package. Three further badges (Quality Lister, Responsive Broker, Super Lister) each track their own sub-metrics (Images Score, Features Score, Calls Answered %, WhatsApp Response %, Active Listings count) but were all Locked at capture time with no visible threshold or "you need N more" messaging — an agent can see the game exists without being told how to win it.
