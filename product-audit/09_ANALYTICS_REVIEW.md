# Analytics Review

Observed KPIs (Overview and Reports Summary):

- Views: 1,675–1,683 (fluctuated slightly between capture passes minutes apart — see Technical Observations)
- Clicks: 34
- Leads: 3
- Calls: 2
- WhatsApp: 1
- SMS: 0
- Emails: 0
- Listing-level views, clicks, and leads (per row, and retained on Removed listings after delisting)
- Credit consumption by listing and upgrade type
- Reports Summary adds: listing composition by purpose/tier, per-district location breakdown (% share), and a daily time series filterable by tier (All/Basic/Hot/Signature) and purpose (All/For Sale/For Rent/Daily Rentals)
- Agent Performance adds a second analytics axis entirely: Images Score, Features Score, Calls Answered %, WhatsApp Response %, Active Listings count, TruPoints™, and a team-level version of the same metrics per staff member

Gaps:

- No visible conversion funnel from impression to lead to deal.
- No benchmark against comparable agencies/listings — percentage deltas like "759%" have no stated baseline period.
- No lead quality score or agent response-time SLA metric surfaced as a number agents are held to (Agent Performance shows the inputs but not a target).
- No visible predictive trend, anomaly detection, or recommended action layer.
- Reports Summary duplicates the dashboard's Performance widget rather than extending it (same tabs, same filters, same date range) — the incremental value is the location breakdown and composition chart, not depth of performance analysis.
- No export (CSV/PDF) control found on Reports Summary.
